# Abdul Rafay | Portfolio

> "Building Things That Matter."

A high-performance, interactive portfolio website designed with a **dark editorial** aesthetic — featuring a custom cursor, film grain overlay, animated typography, and a cinematic layout inspired by modern design studios.

## Tech Stack

* **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
* **UI:** React with inline styles — zero external CSS libraries
* **Fonts:** [Bebas Neue](https://fonts.google.com/specimen/Bebas+Neue), [DM Sans](https://fonts.google.com/specimen/DM+Sans), [Space Mono](https://fonts.google.com/specimen/Space+Mono)
* **Language:** JavaScript (JSX)
* **Deployment:** Vercel

## Key Features

* **Custom Cursor:** A dual-layer cursor with mix-blend-mode difference and a trailing ring, with click-to-expand microinteraction.
* **Film Grain Overlay:** A subtle animated SVG noise texture layered over the entire viewport for a cinematic feel.
* **Animated Hero Text:** Staggered slide-up reveals using CSS transforms and timed delays.
* **Marquee Ticker:** An infinitely scrolling tech-stack banner separating sections.
* **Scroll-Aware Nav:** A sticky navbar that transitions from transparent to frosted glass on scroll.
* **Interactive Project Cards:** Hover-driven color shifts, gradient backgrounds, and animated arrow buttons.
* **Responsive Typography:** All headings use `clamp()` for fluid scaling across viewports.
